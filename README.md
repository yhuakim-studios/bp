# Bakay Pharmacy: website prototype

Next.js 15 (App Router) + React 19 + TypeScript. See **PLAN.md** for the full site plan.

```bash
npm install
npm run dev      # http://localhost:3000
npm run build && npm start
```

- Business details, branches and hours: `lib/site.ts`
- Products (sample data): `lib/products.ts`
- Health Hub articles: `lib/articles.ts`
- Styles / design tokens: `app/globals.css`

Search for `TODO` to find the details that need confirming with the client before launch.
